# The-Frost-Home — Дипломный проект
**Разработка 3D-игры в жанре Survival с системой крафта и динамическими погодными условиями**

**Текущая версия: v0.6**

---

## 🎮 Об игре

The Frost Home — это 3D-игра в жанре выживания, выполненная в сеттинге вечной мерзлоты,
где игроку предстоит бороться за жизнь в суровых условиях на протяжении 10 игровых дней.
Основные механики:

- Исследование мира и сбор ресурсов
- Рубка деревьев и добыча ресурсов
- Создание инструментов и предметов через систему крафта
- Управление здоровьем, голодом и теплом
- Динамическая погода (снег, туман, буран, мороз)
- Прогрессия из 10 дней с нарастающей сложностью

## 🎯 Реализованные системы

### 👤 Персонаж
- Движение (WASD), бег (Shift), прыжок (Space)
- Камера от третьего лица с ограничением углов обзора

### 🎒 Инвентарь
- 90 слотов: 10 хотбар + 80 основных
- Стакание предметов, Drag-and-Drop, выброс предмета

### ⚒️ Крафт
- Рецепты на ScriptableObject — добавляются без изменения кода
- Кнопки крафта ×1 и «Макс»
- Панель крафта открывается клавишей O

### ❤️ Выживание
- Три показателя: здоровье, голод, тепло
- HUD с мигающей индикацией при уровне ниже 25%
- Урон при нулевом голоде или тепле

### 🔥 Костёр
- Источник тепла с зоной действия (SphereCollider-триггер)
- Запас топлива убывает со временем — пополняется брёвнами (клавиша E)
- Три слоя визуальных эффектов: пламя, искры, дым (Particle System)
- Динамическое мерцание точечного света

### 🌨️ Динамическая погода
- 5 профилей: Ясно → Облачно → Снег → Метель → Буран
- Плавный переход между профилями через Mathf.Lerp
- Снег следует за игроком (SnowFollower + Particle System)
- Туман через Unity RenderSettings
- Буран ускоряет потерю тепла в 3.5 раза

### 📅 Система дней и заданий
- 10 игровых дней с нарастающей сложностью
- 4 типа заданий: рубка деревьев, крафт, выживание у костра, сбор предметов
- Прогресс сохраняется через PlayerPrefs
- Переход к следующему дню через взаимодействие с кроватью (E)

## 🕹️ Управление

| Клавиша | Действие |
|---|---|
| W / A / S / D | Движение |
| Shift | Бег |
| Space | Прыжок |
| Мышь | Поворот камеры |
| ЛКМ | Удар топором по дереву |
| E | Подобрать / бросить бревно в костёр / лечь спать |
| F | Съесть предмет из активного слота |
| G | Выбросить предмет из активного слота |
| I | Инвентарь |
| O | Панель крафта |
| 1 – 0 | Выбор слота хотбара |
| Escape | Меню паузы |

## 📅 История версий

  экран смерти и победный экран,
